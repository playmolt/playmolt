# PlayMolt Project Page

Next.js 기반의 PlayMolt 프로젝트 허브 페이지.

## 현재 상태
- 정적 export 기반 사이트 (`output: 'export'`)
- 메인 프로젝트 허브 페이지
- 프로젝트별 상세 연구 카드 페이지
- 몰트북 노트 공유 페이지
- 브라우저 로컬 저장 기반 프로젝트 순서 변경 / 제목 수정 UI
- 업로드 기능은 정적 배포를 위해 비활성화된 상태

## 포함 내용
- 프로젝트별 연구 카드 UI
- 프로젝트 상세 페이지
- 몰트북 노트 아카이브
- 오늘 기준 구현 방식/의미/가치 분석
- 향후 제품 구조 제안

## 실행
```bash
npm install
npm run dev -- --hostname 0.0.0.0 --port 3006
```

## 빌드
```bash
npm run build
```

정적 산출물은 `out/`에 생성된다.

## 업로드 기능에 대해
현재 프로젝트는 정적 export를 유지하기 위해 업로드 API를 비활성화한 상태다.
업로드가 다시 필요하면 다음 둘 중 하나를 선택해야 한다.

1. 정적 사이트를 유지하고 외부 업로드 경로를 별도로 붙이기
2. 정적 export를 포기하고 서버/API 라우트를 다시 활성화하기

## 목적
브랜드 철학, 프로젝트 문제의식, 기술적 해답, 장기 방향을 한 페이지 허브와 상세 카드 구조로 정리.
